# VIDEO — Dona Antônia

Módulo isolado para preparar referências e prompts de vídeo para Google Flow / Gemini Omni Flash 1.1.

## URL oficial
- https://www.donaantonia.com.br/video

## Fluxo
- sorteia 8 produtos ativos com imagem;
- gera 2 referências verticais com 4 produtos em cada;
- gera 1 prompt para um único vídeo de 10 segundos;
- estrutura: 0–2s abertura, 2–8s produtos, 8–10s CTA;
- logo somente no CTA;
- CTA fixo: entrega grátis em Cuiabá e VG, donaantonia.com.br, WhatsApp 98449-1018;
- áudio: somente trilha instrumental, sem voz/locução;
- usa a Edge Function existente creative-storyboard-projects/action=random_products.

Este módulo é separado do Admin e substitui o laboratório legado de stop motion para este fluxo.
