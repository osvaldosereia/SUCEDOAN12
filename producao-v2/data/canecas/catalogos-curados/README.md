# Biblioteca curada de frases para canecas

Esta pasta é a fonte ativa dos 24 catálogos novos do Criador de Canecas.

- Cada frase é texto explícito, escrito para funcionar como estampa/presente.
- Não há gerador por palavras-chave, placeholders ou combinação de moldes.
- Cada catálogo é carregado individualmente somente quando selecionado.
- Os catálogos clássicos Religiosas e Motivacionais permanecem em `../frases-canecas-v1.json`.
- O índice ativo é `index-v2.json`.

O arquivo antigo de catálogos gerados por moldes foi removido para evitar regressão.
