# Arquivo das Edge Functions sem uso

Código das 150 funções publicadas no Supabase que não receberam chamadas entre 21/11 e 28/11/2026, copiado da produção em 28/11/2026. Cada pasta tem os arquivos que a função usava, incluindo as cópias de `_shared/` daquela versão.

Esta pasta fica fora de `supabase/functions/` de propósito: nada aqui é publicado pelo `supabase functions deploy`. Para reativar uma função, mova a pasta para `supabase/functions/`, alinhe os módulos de `_shared/` e rode os testes.

A lista com o uso de cada função está em [docs/inventario-edge-functions.md](../../docs/inventario-edge-functions.md).
