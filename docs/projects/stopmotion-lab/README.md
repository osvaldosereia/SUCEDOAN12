# Stop Motion Lab — catálogo procedural de elementos

## Objetivo
Laboratório mobile 9:16/10s isolado do Studio Criativo principal. Produtos são sorteados do catálogo Dona Antônia e toda edição é global, nunca produto a produto.

## Elementos v1
O motor usa primitivas próprias, sem dependência de GIF/API externa: brilhos (star, diamond/twinkle), formas (circle, ring, triangle), movimento (line, arc, dash) e celebração (confetti/burst/plus). Cada elemento é animado/recolorido pelo Canvas e pode ser ativado/desativado por categoria.

## Paletas
Neon, Pastel, Pop, Tropical e Dark, cada uma com 10 cores.

## Produto
Modos: recortado sem fundo (remoção aproximada da cor das bordas no navegador), papel recortado e original. Tamanho e cadência são globais. Nome do produto não aparece.

## Próximas evoluções
O recorte local é deliberadamente low-cost e funciona melhor em fotos com fundo uniforme. Uma máscara/asset transparente pré-processado deve substituir o recorte aproximado quando houver versão limpa do produto. O catálogo pode receber SVG/PNG próprios/licenciados posteriormente sem alterar o motor.
