## Regra de atualização

Ao final de cada rodada:
- atualizar `CURRENT-STATE.md`;
- atualizar `HANDOFF.md`;
- atualizar `ROADMAP.md` quando uma etapa mudar de estado;
- registrar decisões em `DECISIONS-AND-GUARDRAILS.md`;
- atualizar `TECHNICAL-INVENTORY.md` quando surgirem/removerem componentes.

Nenhuma nova janela deve depender da memória do chat para retomar este projeto.
