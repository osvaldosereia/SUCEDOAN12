# Pedidos — UX operacional e código único

Regra: cada pedido recebe uma única identidade pública na origem e ela não muda durante confirmação, separação, entrega, WhatsApp, impressão ou fiscal.

UX: cards compactos, filtros Pendentes / Em processo / Finalizados / Todos, ação principal única, alertas somente para exceções e detalhes secundários recolhidos.
