# Ame Mais Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir um aplicativo mobile de teste que transforma uma foto de artigo católico em cadastro estruturado, descrição comercial e três imagens de e-commerce compartilháveis.

**Architecture:** Frontend estático em `ame-mais/`, autenticado pelo mesmo fluxo PIN/Admin V3. Backend em uma Supabase Edge Function autenticada, usando GPT-5.6 Luna/Terra para visão estruturada e GPT-Image-2.5 Sunburst para edição de imagem; saídas visuais aprovadas ficam no bucket público `product-images`.

**Tech Stack:** HTML/CSS/JavaScript ES modules, Supabase Auth/Edge Functions/Storage, OpenAI Responses API e Images Edits API, Node test runner para funções puras.

**Spec:** `docs/superpowers/specs/2026-09-12-ame-mais-design.md`

## Global Constraints
- Não salvar produtos no banco nesta versão de teste.
- Não expor `OPENAI_API_KEY` nem `service_role` no navegador.
- Nome segue Tipo → Devoção → Material/Modelo → Cor/Acabamento → Diferencial/Tamanho.
- Devoção com confiança abaixo de 90% não entra no campo final.
- Gerar três imagens: principal fiel em #ECECEC, ambientada e detalhe.
- Compartilhamento precisa funcionar no mobile com fallback para `wa.me`.
