# Catálogo explícito de substituições de cestas v3

- A automação só substitui produtos que pertençam explicitamente à mesma família.
- Cada produto pertence a no máximo uma família; ao adicioná-lo a outra, ele é movido.
- Famílias podem ser criadas, renomeadas, ativadas ou desativadas no Vitrine/Admin.
- Produtos podem ser buscados, adicionados e removidos pelo Admin.
- As regras de estoque, compatibilidade de embalagem e variação máxima de preço continuam obrigatórias.
- A migração inicial preserva os produtos reconhecidos pela classificação legada.
- Alterações no catálogo afetam apenas novas sugestões/regenerações; lotes já aprovados não são modificados.
- Aprovação humana e ativação manual do lote no site continuam obrigatórias.
